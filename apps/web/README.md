# @relayrunner/web

The gateway dashboard: a React SPA on TanStack Router, built with Vite and
served as static assets from a Cloudflare Worker (`relayrunner-app`). The
Worker script (`worker/index.ts`) only forwards `/api/*` to the API Worker over
a service binding, so the dashboard and API share one origin everywhere. The
marketing site lives in `apps/landing`.

## Develop

```sh
cp .env.example .env          # optional
pnpm --dir apps/web dev       # http://localhost:5179
```

`/api` is proxied to the API Worker (`apps/api`, default `http://localhost:8787`).
Set `VITE_AUTH_DISABLED=true` to skip the sign-in guard before the API exists.

## Layout

- `src/router.tsx` exports `getRouter()`, the shape TanStack Start expects, so a
  later move to Start keeps routes and router config unchanged.
- `src/routes/` is file-based. `_authed.tsx` is a pathless layout whose
  `beforeLoad` checks the Better Auth session and redirects to `/login`.
  `_authed/_workspace.tsx` nests inside it: it makes sure the session has an
  active workspace (picking the user's first, or sending them to
  `/workspaces/new`), loads it from `/api/workspaces/current` into route
  context, and draws the sidebar. Pages that act on a workspace live under it.
- `src/lib/auth-client.ts` is the Better Auth React client, pointed at
  `/api/auth` on the same origin.
- `src/routeTree.gen.ts` is generated by the router plugin on `dev`/`build`.
  It is committed so `tsc` works on a fresh checkout.

## Styling

Tailwind v4 (via `@tailwindcss/vite`) with shadcn/ui. The theme lives in
`src/styles.css`: it copies the landing page's tokens from
`apps/landing/DESIGN.md` (near-black slabs, 1px hairlines, Signal Green and
Meter Amber, Hanken Grotesk + JetBrains Mono) and maps them onto shadcn's
semantic variables. It is dark only. The landing names are also Tailwind
colors (`bg-raised`, `text-go`, `border-run-edge`, ...) for route and status UI.

Add components with `pnpm dlx shadcn@latest add <name>` from `apps/web`
(`components.json` is configured). They land in `src/components/ui/`.

## Deploy

`wrangler.jsonc` pins the RelayRunner Cloudflare account (`account_id`); run
`pnpm --dir apps/web run deploy`.
Deploy `apps/api` first: the `API` service binding needs `relayrunner-api` to
exist. In production `app.relayrunner.dev` is this Worker's custom domain, and
`/api/*` reaches the API Worker through the binding, so the API needs no route.
